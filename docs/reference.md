# Reference Study

## References

1. https://cettajapanese.cetta.id/
2. https://nakamurastudyjapan.com/id

Reviewed on 23–24 October 2026 for UX, information architecture, hierarchy, and
conversion patterns only.

Cetta Japanese is the closer match: an online Japanese course with a JLPT-aligned level
ladder, a consultation step, testimonials, and an FAQ. Nakamura Study Japan is a broader
study-and-work consultancy; its useful lessons are about section sequencing, level
diagnosis, and how much detail a long landing page can carry before it stops being
scannable.

## What Cetta Japanese does well

- Leads with a clear promise and a visible next action.
- Uses a long-form landing page that answers questions in a deliberate sequence.
- Presents the course ladder visually, from beginner to advanced.
- Repeats the main call to action after key trust-building sections.
- Uses a consultation/enquiry step rather than pushing directly into a checkout.
- Includes a dedicated FAQ and a final conversion block.
- Makes the course path easy to understand on a phone.

## What Nakamura Study Japan does well

- Splits an otherwise sprawling offer into two named paths ("Pilih Jalurmu"), so a visitor
  self-selects before reading detail.
- Sequences sections as promise → path choice → who we are → services → proof → test →
  next step. Every block has one job.
- Turns an abstract question ("which level am I?") into a concrete tool (a placement test)
  rather than more prose.
- Uses proof with attribution and dates, and keeps it next to the claim it supports.
- Repeats a compact stat pair near the top instead of scattering numbers down the page.

## What this project adopts

- A single-page conversion journey with clear section jobs.
- An explicit, ordered level ladder: Pemula N5 → Dasar N4 → Menengah N3 → Mahir N2,
  presented top to bottom so the sequence is read as a path, not a menu.
- Repeated, but restrained, calls to action.
- A dedicated FAQ before the final CTA.
- A final enrolment block that explains what to do next.
- A "which level do I start at?" answer placed before the level detail, not after it.
- Course presentation that compares levels rather than hiding them behind separate
  navigation.

## What this project does not copy

- No code, markup, CSS, or source files.
- No text, course descriptions, statistics, testimonials, or claims.
- No logos, illustrations, icons, photography, or other assets.
- No brand name, color scheme, type treatment, or exact layout.
- No fabricated student counts, tutor claims, partner logos, or pass rates.
- No WhatsApp number, address, email, social profile, or pricing from either reference.

The Mirski Japanese identity is original: warm cream paper, ink text, a yellow brand
accent, and a display face reserved for headings. The page is in Indonesian and uses only
the supplied Mirski business facts.

## Structural differences

| Reference pattern                          | Mirski decision                                                            |
| ------------------------------------------ | -------------------------------------------------------------------------- |
| Large testimonial wall                     | Three cards at most, and none until real, attributable proof exists.        |
| Many course categories (kaiwa, intensive…) | Focused on the four supplied levels only.                                  |
| Study-abroad and job-placement services    | Out of scope; Mirski is a language course, not a consultancy.              |
| Placement test or gamified placement       | Deferred — needs real question banks and scoring before it can be honest.  |
| WhatsApp-first conversion                  | Internal path CTA plus an honest contact placeholder; no invented channel. |
| Dense promotional sections                 | Fewer sections with more whitespace and editorial pacing.                  |
| Indonesian-language marketing              | Indonesian copy, matching the audience; no Japanese-glyph decoration.      |
| Many course sub-pages                      | One landing page; course detail routes deferred.                           |

## Design principles extracted

1. A prospective learner needs to see the whole path before choosing a starting point.
2. A repeated CTA is useful only when the destination is real.
3. Trust comes from clarity and specificity, not inflated claims.
4. Mobile users need the course ladder and FAQ without deep navigation.
5. A question the page raises ("where do I start?") should be answered on the page, not
   deferred to a form.
6. Proof belongs next to the claim it supports, with attribution.
