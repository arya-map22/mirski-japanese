# Reference Study

## Reference

https://cettajapanese.cetta.id/

Reviewed on 23 October 2026 for UX, information architecture, hierarchy, and conversion
patterns only.

## What the reference does well

- Leads with a clear promise and a visible next action.
- Uses a long-form landing page that answers questions in a deliberate sequence.
- Presents the course ladder visually, from beginner to advanced.
- Repeats the main call to action after key trust-building sections.
- Uses a consultation/enquiry step rather than pushing directly into a checkout.
- Includes a dedicated FAQ and a final conversion block.
- Makes the course path easy to understand on a phone.

## What this project adopts

- A single-page conversion journey with clear section jobs.
- An explicit level ladder: Starter N5 → Elementary N4 → Intermediate N3 → Advanced N2.
- Repeated, but restrained, calls to action.
- A dedicated FAQ before the final CTA.
- A final enrolment block that explains what to do next.
- Course presentation that compares levels rather than hiding them behind separate
  navigation.

## What this project does not copy

- No code, markup, CSS, or source files.
- No text, course descriptions, statistics, testimonials, or claims.
- No logos, illustrations, icons, photography, or other assets.
- No brand name, color scheme, type treatment, or exact layout.
- No fabricated student counts, tutor claims, partner logos, or pass rates.
- No WhatsApp number, address, email, social profile, or pricing from the reference.

The Mirski Japanese identity is original: warm paper, ink, a vermilion seal, editorial
serif display type, and a typographic path motif. The page is in English and uses only
the supplied Mirski business facts.

## Structural differences

| Reference pattern             | Mirski decision                                                            |
| ----------------------------- | -------------------------------------------------------------------------- |
| Large testimonial wall        | Omitted until real, attributable proof exists.                             |
| Multiple program categories   | Focused on the four supplied levels only.                                  |
| WhatsApp-first conversion     | Internal path CTA plus an honest contact placeholder; no invented channel. |
| Dense promotional sections    | Fewer sections with more whitespace and editorial pacing.                  |
| Indonesian-language marketing | English copy, with small Japanese identity accents.                        |
| Many course sub-pages         | One landing page; course detail routes deferred.                           |

## Design principles extracted

1. A prospective learner needs to see the whole path before choosing a starting point.
2. A repeated CTA is useful only when the destination is real.
3. Trust comes from clarity and specificity, not inflated claims.
4. Mobile users need the course ladder and FAQ without deep navigation.
5. The page should end with one unmistakable next step.

## Legal and ethical note

The reference was used for research only. Do not copy its content, assets, or distinctive
visual treatment. When in doubt, create an original composition from the Mirski content
and the design tokens in `docs/design.md`.
